# thanhai-travel

Dự án Landing Page Đặt Xe Riêng & Tiện Chuyến Đẳng Cấp (Executive Cockpit Travel)

## Tính năng chính
- **Giao diện Mobile-First (Above the fold):** Trải nghiệm khoang lái xe sang, mở ra đặt xe ngay lập tức không cần cuộn trang.
- **Phong cách Dynamic Luxury Cockpit:** Nền đen OLED `#04060A`, viền ánh kim Champagne Gold `#E5C378`, đèn báo Neon Laser Emerald `#00F59B`.
- **Micro-Animations:**
  - Vệt sáng kim loại Shimmer Beam quét ngang nút đặt xe.
  - Chấm trạng thái Radar Pulse phát nhịp tim báo online.
  - Smooth Counter chuyển đổi giá cước mượt mà.
  - Phím gạt rãnh chìm Tactile Switch (Bao xe vs Ghép chuyến).
- **Tự động nhận đơn:**
  - Gửi thông báo tức thì qua Telegram Bot Webhook API.
  - Mở Zalo Deep Link điền sẵn nội dung cuốc xe chi tiết.
- **Bảng quản trị (`admin.html`):**
  - Khóa bảo mật mã PIN 4 số.
  - Công tắc 1-chạm bật/tắt phụ thu Lễ/Tết (% hoặc tiền mặt).
  - Cập nhật banner xe rỗng chiều về tiện chuyến tức thì.
  - Quản lý và chỉnh sửa trực tiếp bảng giá các tuyến đường.
